# 🟢 LEAD STORE — دليل النشر

موقعك (متجر ليد للخدمات الرقمية) جاهز للنشر. يتكوّن من:
- **Next.js** (واجهة + API)
- **PostgreSQL** (قاعدة البيانات — فيها المنتجات والأسعار والإعدادات وكلمة سر الأدمن)

> ✨ **ملاحظة مهمة:** عند النشر على قاعدة بيانات **جديدة وفاضية**، الموقع بيملّي
> تلقائيًا بكل المنتجات الحالية (12 منتج) والإعدادات وكلمة سر لوحة التحكم
> (`Leadhcomatore772_uj`). ما تحتاج تعيد إدخال أي شي يدويًا.

---

## الخيار الموصى به: Vercel + Neon (مجاني في البداية)

Vercel يستضيف الموقع، وNeon يستضيف قاعدة البيانات. كلاهما فيه باقة مجانية تكفي للبداية.

### 1) أنشئ قاعدة البيانات (Neon)
1. افتح [neon.tech](https://neon.tech) وسجّل حساب مجاني.
2. اضغط **New Project** واختر أقرب منطقة.
3. بعد الإنشاء، انسخ **Connection String / Database URL** (يبدأ بـ `postgresql://…?sslmode=require`).
4. احفظ هذا الرابط — راح تحتاجه بالخطوة 3.

### 2) ارفع الكود على GitHub
1. افتح [github.com](https://github.com) وسجّل حساب مجاني (أو استعمل حسابك).
2. اضغط **New repository** واكتب اسم مثل `lead-store` ثم أنشئه.
3. ارفع ملفات المشروع على هذا المستودع (من GitHub: Add files → Upload files، أو عبر `git` على جهازك).

### 3) اربط الموقع (Vercel)
1. افتح [vercel.com](https://vercel.com) وسجّل **بنفس حساب GitHub**.
2. اضغط **Add New → Project** واختر مستودع `lead-store`.
3. Vercel بيكشف تلقائيًا إنه مشروع Next.js.
4. في خانة **Environment Variables**، أضف:
   - **Name:** `DATABASE_URL`
   - **Value:** الصق رابط Neon اللي نسخته من الخطوة 1
   > ⚠️ أضف هذا **قبل** الضغط على Deploy عشان البناء ينجح من أول مرة.
5. اضغط **Deploy**.

### 4) بعد النشر 🎉
- خلال دقائق بيطلع لك رابط مجاني مثل: `lead-store.vercel.app`
- افتح الموقع — كل المنتجات والأسعار والإعدادات تكون جاهزة تلقائيًا.
- **لوحة التحكم:** `https://lead-store.vercel.app/admin`
- **كلمة السر:** `Leadhcomatore772_uj`

## تحديث الموقع لاحقًا
عدّل الكود محليًا → ارفع التغييرات على GitHub → Vercel بيحدّث الموقع تلقائيًا بدون ما تضغط أي شي.

## أي شي تبي تعديله بدون كود؟
ادخل `/admin` بكلمة السر وعدّل: المنتجات، الأسعار، الصور، النصوص، رقم الواتساب، رابط الديسكورد — كل شي ينحفظ بقاعدة البيانات وينعكس فورًا.
